# v0.11.1 — Page builder hidden in production

The page builder (multi-page sites + the in-canvas section editor) is **hidden in
production** for now — it needs more time in the oven. The **links editor stays**
as the live editor, and public pages render the classic links page. Nothing is
deleted: all builder code and any saved builder data stay put and reappear the
moment the flag is turned back on.

## What changed

- The page builder is now gated behind `BUILDER_ENABLED` on **every** surface —
  creator (the dashboard entry + `/dash/builder`) **and** visitor (public section
  pages, subpages, and the site nav). Previously the visitor side rendered builder
  pages regardless of the flag.
- With the flag off in production: the dashboard leads with the links editor,
  `/dash/builder` is a 404, public profiles render the classic links page, and
  `/<username>/<slug>` subpages 404.

No data migration and nothing removed — flipping `BUILDER_ENABLED` back on restores
the builder and every saved page exactly as it was.
