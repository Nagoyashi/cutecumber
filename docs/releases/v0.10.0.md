# v0.10.0 — A builder that behaves

Phase A of the creator-platform overhaul: making the page builder actually feel
like a product. This release is all reliability and feel — no new surface, and no
change to the page a visitor loads.

## Save that doesn't lie

- Uploading a gallery photo and then losing it on reload was the loudest paper
  cut. The upload itself always worked — but the whole-page autosave was silently
  all-or-nothing: **one** invalid section (a blank hero name, a bad link, a
  premium section on a free plan) dropped the *entire* draft, with only a tiny
  status word to show for it. Now a failed save is a **loud, persistent red "not
  saved" pill** with the full reason on hover, and it clears the moment the next
  save succeeds. (#102)
- The error **points to the culprit**: save/publish report which section failed;
  the pill reads "· click to jump there" and **selects + scrolls to** that
  section, so you're not hunting a long page for the problem. (#103)

## Smoother editing

- Gallery photo uploads show a **per-photo "uploading…" spinner**, then swap to
  the thumbnail — no more wondering if it worked. (#102)
- **Drag-to-reorder** no longer rebuilds the whole page on every pointer move —
  only a drop-line indicator moves, so it stays smooth on long pages; plus edge
  auto-scroll when you drag past the top or bottom. (#103)
