# v0.8.0 — Page builder, live (allowlist-gated)

`v0.7.0` landed the page builder as code behind a flag; **`v0.8.0` turns it on in
production** for an allowlist. Nothing changes for visitors, or for creators
outside the allowlist — the legacy links editor stays the default and
`/dash/builder` is a plain 404 to everyone else (no hint the surface exists).
This release is the flip, plus the editor-polish and security-verification work
that gated it.

## Turned on in production

- **The flip** (#83): `BUILDER_ENABLED` + `BUILDER_ALLOWLIST` set as Fly secrets;
  allowlisted creators reach `/dash/builder`, everyone else gets a 404. Public
  pages are unchanged — same strict CSP; the builder's scoped exceptions apply
  only to pages that actually use those sections.
- No new migration: the additive `sections_draft_json` / `sections_live_json` /
  `plan` columns already shipped (additive, nullable) in `v0.7.0`.

## Verified before the flip

- **The public-page exceptions, in a real browser** (#34, `DECISIONS.md` #38):
  the custom-HTML sandbox blocks scripts and network — no exfil reached the
  origin, and an off-origin image was blocked by the frame's own CSP; embeds stay
  click-to-load, so no third-party request fires until the visitor clicks; and
  the CSP exceptions are armed only on pages that use those sections — every
  other page stays `default-src 'none'`.
- **Owner device QA** (#34): Chrome DevTools Lighthouse (mobile + desktop) and the
  on-phone signup → claim → avatar → reset → public-page walkthrough.

## Editor polish (#85)

- The template picker shows a **live scaled miniature** of each starter page in
  its own palette, instead of text-only cards.
- **Publish popover**: publishing opens a small popover — "your patch is live!",
  a copy-URL button, and a sprout domain teaser for free users — in place of the
  quiet status word.
- **Accessibility**: the button-grid inspector fields (avatar, motif, link/photo
  rows) are grouped with `role="group"`, so a field's label no longer activates
  its first control; single-input fields keep their `<label>`.

## Billing — deliberately deferred (#84)

Real billing (Stripe) is out of this cycle by design and is **not** a flip
blocker: allowlist gating plus the staging plan toggle exercise the `sprout` tier
without a payment processor. It's revisited only when the builder opens beyond
the allowlist, or needs a self-serve upgrade path (`DECISIONS.md` #38).

## Notes

The builder is live for the allowlist only — still not exposed to the public.
Opening it more widely, and real billing, are future cycles. Two low-priority
editor-polish items (prototype spacing/type, drag smoothness) are tracked in #86.
