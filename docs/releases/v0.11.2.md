# v0.11.2 — Live colour preview

Tweak a colour in your dashboard theme and the preview updates **instantly** —
background, surface, text and accent all repaint as you pick, before you save
anything. Only "save" persists it.

## What changed

- The dashboard's live preview now reflects **colour tweaks in real time**.
  Because the preview is the real public page (same origin), the dashboard just
  overrides its CSS custom properties (`--bg`, `--bg2`, `--surface`, `--text`,
  `--accent`, plus a computed `--accent-text`) as you move the colour pickers.
  Nothing is saved until you click **save** — reloading without saving discards
  the preview.
- Under the hood, the public page's background now references those CSS vars
  (identical rendering) so a colour change can repaint without a server
  round-trip. Public pages stay **zero-JS**.

Note: for now the *colour* controls preview live; font, button style, background
pattern and layout still apply on save.
